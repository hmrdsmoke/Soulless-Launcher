# Soulless Launcher — User Config

Config directory: `~/.config/soulless/`

## Backgrounds

Drop images into `~/.config/soulless/backgrounds/`

The first image alphabetically is used as the right panel background.

### Recommended dimensions
- **Width:** 460px
- **Height:** 1100px minimum (1488px ideal)
- **Formats:** PNG, JPG, JPEG, WEBP
- **Aspect ratio:** Portrait (tall) — roughly 1:3

### Notes
- Images are resized automatically to fit the panel
- Too short = black gap at bottom
- Too wide = cropped from center
- Restart the launcher after swapping backgrounds

## Drawer State

Drawers are saved to `~/.local/share/soulless/drawers.json`
